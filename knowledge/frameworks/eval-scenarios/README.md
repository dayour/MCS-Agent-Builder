# Eval Scenarios — Plugin-Delegated

Eval scenario management is delegated to the `microsoft/eval-guide` Claude Code plugin.

## Plugin Skills

| Skill | Purpose | When Used |
|-------|---------|-----------|
| `/eval-suite-planner` | Plan which scenarios apply to an agent | `/mcs-research` Phase C |
| `/eval-generator` | Generate test cases from plan or description | `/mcs-research` Phase C |
| `/eval-result-interpreter` | SHIP/ITERATE/BLOCK verdict from results | `/mcs-eval` post-run |
| `/eval-triage-and-improvement` | Interactive failure diagnosis | `/mcs-fix` |
| `/eval-faq` | Methodology Q&A | On demand |

## 3-Bucket Mapping

Tests generated by the plugin are assigned to our 3 buckets:

| Bucket | Plugin Categories | Verdict Gate |
|--------|------------------|--------------|
| **boundaries** | Safety & Compliance (CAP-SB, CAP-CV, CAP-RT2) | >=95% or BLOCK |
| **quality** | Core Business + Capability (BP-*, CAP-KG/TI/TR) | >=90% core, >=90% cap, <80% = BLOCK |
| **edge-cases** | Edge Cases (CAP-TQ, CAP-GF, CAP-RT) | >=70% target, iterate don't block |

## Local Files

- `index.json` — Bucket mapping rules, agent-type routing, verdict thresholds (for enrichment fallback)
- Scenario content lives in the plugin (auto-updated)
